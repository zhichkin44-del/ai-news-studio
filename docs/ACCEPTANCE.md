# Приёмка этапа 3 «Сбор»

Радар (`npm run radar`) работает без перерыва 3 суток. Затем `npm run metrics -- --hours 72` — цифры берутся из `docs/eval/metrics-latest.json`. Пороги стартовые, потом калибруются по замеру.

| № | Критерий | Порог | Где смотреть |
|---|----------|-------|--------------|
| 1 | Каждая лента жива | ≥ 1 свежая запись (младше 6 ч) на момент замера; доля опросов с ошибкой < 5 % | `feeds[].fresh_6h`, `feeds[].error_rate`; `problem_feeds` пуст |
| 2 | Скорость | медиана задержки (first_seen − published) ≤ 5 мин для RSS-лент (все текущие ленты — RSS) | `latency.median_sec` ≤ 300; по лентам — `feeds[].latency` |
| 3 | Без повторов | ≥ 90 % записей в базе с уникальной ссылкой | `unique_items_share` ≥ 0.9 |
| 4 | Подтверждение | ≥ 25 % событий имеют 2+ независимых источника (ленты одного издателя считаются за одного) | `multi_source_share` ≥ 0.25 |
| 5 | Полнота | покрытие базой ≥ 80 % от ручного списка 20 главных событий дня | см. ниже |

## Оговорки к замеру

- Задержка считается без записей первого опроса каждой ленты (`baseline`): это накопленная история, а не «пришло к нам». Поэтому замер начинается со второго прохода.
- Если у ленты нет даты публикации, запись в задержку не входит.
- `duplicates_merged_share` (доля записей, склеенных в кластеры) — справочная, порога нет: нужна для калибровки склейки.

## Сверка полноты (критерий 5)

Делает вручную Рита или владелец, не код.

1. В день замера составить `docs/eval/reference-top-<ГГГГ-ММ-ДД>.json` — массив из 20 объектов `{"title": "<событие своими словами>", "note": "<по желанию>"}`: главные события дня в мире.
2. Для каждого события проверить, есть ли оно в базе за этот день (поиск по `items.title` в `data/news.db` или по событиям из `npm run metrics`), и отметить `"covered": true/false`.
3. Покрытие = covered / 20 ≥ 0.8. Пропущенные события разобрать: нет в лентах (нужен новый источник) или есть, но не склеено (калибровка кластеров).

## Итог

Этап принят, если выполнены все 5 критериев. Не выполнен критерий — в отчёте указать какой и что меняем (лента, порог, источник).
